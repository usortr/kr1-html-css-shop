# Учебный frontend-проект (Контрольная работа №1)

## Описание
Проект выполняется в рамках дисциплины «Фронтенд и бэкенд разработка».
Тема: «HTML и CSS: разработка многостраничного сайта».
Данный репозиторий содержит итоговую версию проекта, выполненную с расширенной функциональностью для получения максимальной оценки.

## Ссылка на опубликованный проект
GitHub Pages: https://usortr.github.io/kr1-html-css-shop/

## Структура проекта
- `index.html` — главная страница (hero, преимущества, популярные товары);
- `catalog.html` — каталог товаров с фильтрами;
- `product.html` — детальная карточка товара с таблицей характеристик;
- `order.html` — отдельная страница оформления заявки;
- `contacts.html` — контактная информация;
- `css/style.css` — файл стилей с БЭМ-архитектурой;
- `js/main.js` — базовая интерактивность (модалка, валидация, кнопка "Наверх");
- `images/` — папка для изображений;
- `README.md` — описание проекта;
- `.gitignore` — исключённые файлы.

## Используемые технологии
- HTML5 (семантическая разметка, формы, таблицы, доступность a11y);
- CSS3 (переменные, Flexbox, CSS Grid, псевдоклассы состояний);
- Методология БЭМ для именования классов;
- Vanilla JavaScript (DOM-манипуляции, валидация форм, события скролла);
- Git, GitHub, GitHub Pages.

## ✅ Самостоятельные доработки (для повышенной оценки)
В соответствии с требованиями КР №1, проект был существенно расширен сверх базовых пошаговых инструкций:
1. **Добавлены обязательные страницы**: реализованы `product.html` и `order.html`, что обеспечивает полноценную многостраничную структуру.
2. **Демонстрация всех типов позиционирования CSS**:
   - `position: relative` + `absolute` + `z-index` для бейджей «Хит» и «Скидка» на карточках товаров.
   - `position: sticky` для боковой панели фильтров в каталоге (фильтры остаются видны при прокрутке).
   - `position: fixed` для кнопки «Вернуться наверх», появляющейся при скролле.
3. **Семантическая таблица**: на странице `product.html` добавлена таблица характеристик (`<table>`, `<caption>`, `<thead>`, `<tbody>`, `<th>`, `<td>`) с корректным CSS-оформлением.
4. **Улучшенная доступность (a11y)**: все интерактивные элементы имеют видимый фокус (`:focus-visible`), формы связаны через `label` + `for`, добавлены `aria-label` для навигации.
5. **Расширенная валидация**: JavaScript проверяет форму перед отправкой, подсвечивает ошибочные поля через атрибут `aria-invalid="true"` и показывает toast-уведомление об успехе.

## БЭМ-структура проекта
- `site-header`, `site-nav`, `site-footer` — шапка, навигация, подвал;
- `product-card`, `product-card--hit`, `product-card--discount`, `product-card__badge` — карточка товара и её модификаторы;
- `catalog-layout`, `catalog-filters` — сетка каталога и липкие фильтры;
- `order-form`, `order-dialog` — формы и модальные окна;
- `back-to-top` — фиксированная кнопка прокрутки наверх.

## Как проверить проект
1. Откройте [GitHub Pages ссылку](https://usortr.github.io/kr1-html-css-shop/).
2. Протестируйте навигацию между всеми 5 страницами.
3. На странице **Каталога** прокрутите вниз, чтобы увидеть, как фильтры "прилипают" к верху экрана (`sticky`).
4. Наведите курсор на карточки товаров, чтобы увидеть бейджи (`absolute`).
5. Откройте **Карточку товара**, чтобы проверить таблицу характеристик.
6. Попробуйте отправить форму с ошибками, чтобы увидеть JS-валидацию и подсветку полей.
7. Прокрутите страницу вниз, чтобы появилась кнопка «Наверх» (`fixed`).
